## Project Overview
PharmaGo is a mobile application designed to help customers quickly find medicines in nearby pharmacies, check real-time availability, compare prices, upload prescriptions, and place orders for delivery.  
Pharmacy owners can manage stock and confirm orders, delivery riders can update delivery status, and admins can monitor the system.

## Features
- Medicine search with GPS-based nearby pharmacy identification  
- Real-time stock updates from pharmacies  
- Prescription upload and validation  
- Order placement, confirmation, and notifications  
- Delivery assignment and tracking  
- Admin management of users, complaints, and fake listings
